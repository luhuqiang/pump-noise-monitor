}
function Write-Log {
  param([string]$Text)

}
function Get-JsonText {

  return ""
}

## 9. 失败与回退

| 情形 | 判定 | 回退动作 |
|---|---|---|
| 任一裁决空白 | G0 不通过 | 补裁决与签字；不得进入 S1 |
