### 3.1 发布四元组口径

`release-card.json` 的 `build`、`commit`、`apk_sha256`、`cert_sha256` 四项必须同时满足：

- `build` 非空，且与本次发布构建一致。
- `commit` 等于 `git rev-parse HEAD`，并等于 `v2.0.0` tag 指向的 commit。
- `apk_sha256` 等于 `听诊仪-2.0.0.apk` 的实算 SHA-256。
- `cert_sha256` 等于 `evidence/step-0/cert-sha256.txt` 的 1.4 基线证书 SHA-256。

### 3.2 `gt45-coverage.md` 固定机器可读字段

```text
GT45=Build 4 覆盖安装到 v2.0.0
versionCode_before=4
versionCode_after=6
baseline_before=12
baseline_after=12
case_before=3
case_after=3
report_before=1
report_after=1
```

> 上面的 12/3/1 仅为格式示例，**必须替换成现场实测条数**；照抄示例视为伪造证据。`baseline_after`、`case_after`、`report_after` 必须分别大于或等于覆盖前的值。

### 3.3 `coverage-install.md` 必须包含

- 设备型号、Android 版本、安装时间、执行人。
- Build 4 安装成功（`versionCode=4`）。
- 覆盖安装 `听诊仪-2.0.0.apk` 成功（`versionCode=6`、同证书）。
- 资产、测点、基线、报告迁移后可见；`migration_id` 有记录。
- 新采一次会话可正常；旧基线在几何一致时可比较。
- 导出 `.tzcase` 含旧案例，且 `raw_available=false`。
- 6 张截图路径与 `evidence/release/screenshots/` 一一对应。

## 4. 自动验收命令块（PowerShell 5，复制即跑）

> 在项目根目录 `d:\Users\Documents\Trae-CN\pump-noise-monitor` 执行。
> `npm run apk` 生成 `听诊仪.apk` 后，本脚本复制为发布名 `听诊仪-2.0.0.apk`；复制不改包内容与签名。
> 自动脚本不重跑 GT/F；GT45 的覆盖动作由第 6 节人工执行并留证据，本脚本只校验记录。

```powershell
# ===== S12 自动验收（PowerShell 5）=====
$ErrorActionPreference = "Continue"

# ===== 本步参数 =====
$Step                = "S12"
$Apk                 = ".\听诊仪-2.0.0.apk"
$SourceApk           = ".\听诊仪.apk"
$Build4Apk           = ".\legacy\pump-noise-handover-20261102\android\pumpnoise-build4-v1.3.apk"
$ExpectVC            = 6
$ExpectVN            = "2.0.0"
$ExpectPackage       = "com.luhuqiang.pumpnoise"
$MinTests            = 70
$MinKB               = 350
$MaxKB               = 900
$RequiredStrings     = @()            # N/A：S12 无 UI 字符串门禁
$ForbiddenEntries    = @("postgres.wasm", ".gguf")
$RequiredEntries     = @("AndroidManifest.xml", "classes.dex", "assets/www/index.html")
$MinSamples          = 0              # N/A：样本已在 S10 冻结
$RequireReviews      = @(12, 15, 16)
$ReleaseTag          = "v2.0.0"
$ReleaseDir          = "evidence/release"
$EvidenceDir         = "evidence/step-$Step"
$RunNpmCi            = $false         # N/A：依赖已在 S1 验证
$SkipPgliteCheck     = $false
$RunApkBuild         = $true

# ===== 初始化 =====
$results = @()
New-Item -ItemType Directory -Force -Path $EvidenceDir | Out-Null
New-Item -ItemType Directory -Force -Path $ReleaseDir | Out-Null
$log = Join-Path $EvidenceDir "verify.log"
"# verify $Step $(Get-Date -Format o)" | Set-Content -Path $log -Encoding UTF8

function Add-Result {
  param([string]$Name, [string]$Status, [string]$Detail)
  $script:results += @{ Check = $Name; Status = $Status; Detail = $Detail }
}
function Write-Log {
  param([string]$Text)
  Write-Host $Text
  Add-Content -Path $script:log -Value $Text -Encoding UTF8
}

# ===== 1. 依赖（N/A） =====
Add-Result "npm-ci" "N/A" "依赖已在 S1 用 npm ci 验证；本步不重装"

# ===== 2. 类型检查 =====
$tcOut = (npm run typecheck 2>&1 | Out-String)
Write-Log $tcOut
$tcExit = $LASTEXITCODE
if ($tcExit -eq 0) { Add-Result "typecheck" "Pass" "exit=0" } else { Add-Result "typecheck" "Fail" "exit=$tcExit" }

# ===== 3. 单元测试 =====
$testOut = (npm test 2>&1 | Out-String)
Write-Log $testOut
$mPass = [regex]::Match($testOut, "# pass (\d+)")
$mFail = [regex]::Match($testOut, "# fail (\d+)")
$passCount = 0
$failCount = 999
if ($mPass.Success) { $passCount = [int]$mPass.Groups[1].Value }
if ($mFail.Success) { $failCount = [int]$mFail.Groups[1].Value }
if (($failCount -eq 0) -and ($passCount -ge $MinTests)) {
  Add-Result "tests" "Pass" "pass=$passCount fail=$failCount need>=$MinTests"
} else {
  Add-Result "tests" "Fail" "pass=$passCount fail=$failCount need>=$MinTests"
}

# ===== 4. 前端构建 =====
$buildOut = (npm run build 2>&1 | Out-String)
Write-Log $buildOut
$buildExit = $LASTEXITCODE
$distOk = Test-Path ".\dist\index.html"
if (($buildExit -eq 0) -and $distOk) {
  Add-Result "vite-build" "Pass" "exit=0 dist/index.html=True"
} else {
  Add-Result "vite-build" "Fail" "exit=$buildExit dist/index.html=$distOk"
}

# ===== 5. 打包 + 签名 + 复制发布名 =====
$apkOut = (npm run apk 2>&1 | Out-String)
Write-Log $apkOut
$apkBuildExit = $LASTEXITCODE
if (($apkBuildExit -eq 0) -and (Test-Path $SourceApk)) {
  Copy-Item -Path $SourceApk -Destination $Apk -Force
}
$apkOk = Test-Path $Apk
if (($apkBuildExit -eq 0) -and $apkOk) {
  Add-Result "apk-build" "Pass" "exit=0 apk=$apkOk"
} else {
  Add-Result "apk-build" "Fail" "exit=$apkBuildExit apk=$apkOk"
}

# ===== 6. check-apk =====
$checkOut = (npm run check:apk -- $Apk 2>&1 | Out-String)
Write-Log $checkOut
$checkExit = $LASTEXITCODE
$checkOk = ($checkExit -eq 0) -and ($checkOut -match '"ok"\s*:\s*true') -and ($checkOut -match '"brokenRefs"\s*:\s*\[\s*\]')
if ($checkOk) { Add-Result "check-apk" "Pass" "exit=0 ok=true brokenRefs=[]" } else { Add-Result "check-apk" "Fail" "exit=$checkExit ok=$checkOk" }
$checkOut | Set-Content -Path (Join-Path $EvidenceDir "check-apk.json") -Encoding UTF8
$checkOut | Set-Content -Path (Join-Path $ReleaseDir "check-apk.json") -Encoding UTF8

# ===== 7. 版本与包名 =====
$vcM = [regex]::Match($checkOut, '"versionCode"\s*:\s*(\d+)')
$vnM = [regex]::Match($checkOut, '"versionName"\s*:\s*"([^"]+)"')
$pkgM = [regex]::Match($checkOut, '"package"\s*:\s*"([^"]+)"')
$vc = if ($vcM.Success) { [int]$vcM.Groups[1].Value } else { 0 }
$vn = if ($vnM.Success) { $vnM.Groups[1].Value } else { "" }
$pkg = if ($pkgM.Success) { $pkgM.Groups[1].Value } else { "" }
if (($vc -eq $ExpectVC) -and ($vn -eq $ExpectVN) -and ($pkg -eq $ExpectPackage)) {
  Add-Result "version-package" "Pass" "vc=$vc vn=$vn pkg=$pkg"
} else {
  Add-Result "version-package" "Fail" "vc=$vc vn=$vn pkg=$pkg expect=$ExpectVC/$ExpectVN/$ExpectPackage"
}

# ===== 8. 签名 v2/v3 与内容指纹 =====
$v2ok = $checkOut -match '"v2"\s*:\s*true'
$v3ok = $checkOut -match '"v3"\s*:\s*true'
if ($v2ok -and $v3ok) { Add-Result "signature-v2-v3" "Pass" "v2=true v3=true" } else { Add-Result "signature-v2-v3" "Fail" "v2=$v2ok v3=$v3ok" }
$contentM = [regex]::Match($checkOut, '"contentSha256"\s*:\s*"([0-9a-fA-F]{64})"')
if ($contentM.Success) { Add-Result "content-sha256" "Pass" $contentM.Groups[1].Value } else { Add-Result "content-sha256" "Fail" "缺 contentSha256" }

# ===== 9. 证书 SHA（必须与 1.4 基线一致） =====
$certM = [regex]::Match($checkOut, '"certSha256"\s*:\s*"([0-9a-fA-F]{64})"')
$cert = if ($certM.Success) { $certM.Groups[1].Value.ToLower() } else { "" }
$cert | Set-Content -Path (Join-Path $EvidenceDir "cert-sha256.txt") -Encoding UTF8
$cert | Set-Content -Path (Join-Path $ReleaseDir "cert-sha256.txt") -Encoding UTF8
$baselineFile = ".\evidence\step-0\cert-sha256.txt"
$baselineCert = ""
if (Test-Path $baselineFile) {
  $baselineText = Get-Content $baselineFile -Raw -Encoding UTF8
  $baselineM = [regex]::Match($baselineText, '([0-9a-fA-F]{64})')
  if ($baselineM.Success) { $baselineCert = $baselineM.Groups[1].Value.ToLower() }
}
if (($cert.Length -eq 64) -and ($cert -eq $baselineCert)) {
  Add-Result "cert-sha256" "Pass" "cert=$cert baseline=$baselineCert"
} else {
  Add-Result "cert-sha256" "Fail" "cert=$cert baseline=$baselineCert（禁止换证书）"
}

# ===== 10. APK 体积 =====
if (Test-Path $Apk) { $sizeKB = [math]::Round((Get-Item $Apk).Length / 1KB, 1) } else { $sizeKB = 0 }
"APK_SIZE_KB=$sizeKB (need $MinKB-$MaxKB)" | Set-Content -Path (Join-Path $EvidenceDir "apk-size.txt") -Encoding UTF8
if (($sizeKB -ge $MinKB) -and ($sizeKB -le $MaxKB)) {
  Add-Result "apk-size" "Pass" "$sizeKB KB (need $MinKB-$MaxKB)"
} else {
  Add-Result "apk-size" "Fail" "$sizeKB KB (need $MinKB-$MaxKB)"
}

# ===== 11. APK SHA-256 =====
$apkHash = ""
if (Test-Path $Apk) { $apkHash = (Get-FileHash $Apk -Algorithm SHA256).Hash.ToLower() }
$apkHash | Set-Content -Path (Join-Path $EvidenceDir "apk-sha256.txt") -Encoding UTF8
$apkHash | Set-Content -Path (Join-Path $ReleaseDir "apk-sha256.txt") -Encoding UTF8
if ($apkHash.Length -eq 64) { Add-Result "apk-sha256" "Pass" $apkHash } else { Add-Result "apk-sha256" "Fail" "hash=$apkHash" }

# ===== 12. UI 字符串（N/A） =====
"N/A: S12 无 UI 字符串门禁" | Set-Content -Path (Join-Path $EvidenceDir "ui-strings.txt") -Encoding UTF8
Add-Result "ui-strings" "N/A" "S12 无 UI 字符串门禁"

# ===== 13. APK 条目（禁止 / 必须） =====
$entries = $null
if (Test-Path $Apk) {
  if (Get-Command jar -ErrorAction SilentlyContinue) {
    $entries = @(jar tf $Apk 2>$null)
  } elseif (Get-Command unzip -ErrorAction SilentlyContinue) {
    $entries = @(unzip -Z1 $Apk 2>$null)
  }
}
if (($entries -eq $null) -or ($entries.Count -eq 0)) {
  Add-Result "apk-entries" "Fail" "jar/unzip 不可用或包为空"
} else {
  $entries | Set-Content -Path (Join-Path $EvidenceDir "apk-entries.txt") -Encoding UTF8
  foreach ($f in $ForbiddenEntries) {
    $hit = @($entries | Select-String -Pattern $f -SimpleMatch).Count

  }
  foreach ($f in $RequiredEntries) {
    $hit = @($entries | Select-String -Pattern $f -SimpleMatch).Count
    if ($hit -ge 1) { Add-Result "required-entry:$f" "Pass" "hits=$hit" } else { Add-Result "required-entry:$f" "Fail" "hits=0" }
  }
}

$srcFiles = @(Get-ChildItem ".\src" -Recurse -File -ErrorAction SilentlyContinue | Where-Object { $_.Extension -in @(".ts", ".tsx") })

"N/A: 样本已在 S10 冻结并验收" | Set-Content -Path (Join-Path $EvidenceDir "samples.txt") -Encoding UTF8
Add-Result "samples" "N/A" "样本已在 S10 冻结并验收"

# ===== 16. 评审 12/15/16（3/3） =====
$revDir = ".\evidence\reviews"
$revIndex = Join-Path $revDir "index.csv"

if (($revRows.Count -ge 3) -and ($revMissing -eq 0)) {

} else {

}
if ($revBadStatus -eq 0) { Add-Result "review-status-missing" "Pass" "missing=0" } else { Add-Result "review-status-missing" "Fail" "missing=$revBadStatus" }
if ($revEmptyConclusion -eq 0) { Add-Result "review-conclusion" "Pass" "结论非空 3/3" } else { Add-Result "review-conclusion" "Fail" "空结论=$revEmptyConclusion" }

$revFileMissing = 0
$revShaBad = 0

  if (($st -ne "recovered") -and ($st -ne "recreated")) { $revStatusBad++ }

  }

}
if ($revStatusBad -eq 0) { Add-Result "review-status-valid" "Pass" "recovered/recreated 合法" } else { Add-Result "review-status-valid" "Fail" "bad=$revStatusBad" }
if ($revFileMissing -eq 0) { Add-Result "review-files" "Pass" "3/3 存在" } else { Add-Result "review-files" "Fail" "missing=$revFileMissing" }
if ($revShaBad -eq 0) { Add-Result "review-sha256" "Pass" "3/3 与索引一致" } else { Add-Result "review-sha256" "Fail" "mismatch=$revShaBad" }
```
