| # | 决策 | 对开发的硬约束 |

## 5. 硬约束（不可改）

- **绝对 SPL 不可测**：只做相对/趋势与门限判断，不承诺 dB SPL 绝对值。
- **单麦不可分离**：单麦模式下不做源分离，只给“疑似/需复测”。
- **只放行汽蚀与堵塞**：其余机制不出结论。
- **默认不留原始音频**：`retain_raw=false`，片段默认关闭。
- **纯本地无云**：无网络依赖、无上传、无在线监护。
