# 01 · 第一性原理解构

> 结论先行：旧方案不是“算法不够好”，而是**把三个不可观测的量当成了可观测**：绝对声压级、声源身份、故障名称。
> 听诊仪要做的是把这三个量换成**可观测的替身**：相对声级、机制家族、验证实验。

## 0. 结论先行（7 条）

1. **最致命假设 A：dBFS + 一个常数 = dB SPL。** 手机 MEMS 灵敏度逐机 ±3dB、频响 100Hz–10kHz ±3dB、AGC 时变、OS 可能做 NS/AEC/波束成形；绝对 SPL 的不确定度 **>±5dB**，不具备计量意义。[F]
2. **最致命假设 B：单麦克风可以分离/定位声源。** 单通道只有 0 个空间自由度；观测是 \(X(f)=\sum_k S_k(f)H_k(f)+N(f)\)，K 个源 + 未知传递函数，1 个方程解不出；盲分离必须靠先验，不是物理可逆。[F]
3. **最致命假设 C：稳态谱 + 自学习基线可以“命名故障”。** 1× 可能来自不平衡、共振、电磁或流致；2× 可能来自不对中、叶片通过或 100Hz 电源线；同一谱形对应多机制，故障名**不可辨识**，除非有拆检真值标注。[F/I]
4. **第四个致命假设 D：门限可以随劣化自适应。** 滚动 median/MAD 会把“变坏”学成“新正常”；crest/kurtosis 门限必须**冻结在验收健康期**，否则检测延迟无限增长。旧代码已改为冻结门 + 未冻结只记录，本产品继承。[F]
5. **长积分不是“更准”，是“用时间换频率分辨率”。** Δf=1/T；32768 点 @48k = 0.6827s → 1.465Hz；46Hz 的 1% 边带需 T≥2.2s。但泵工况非稳态，现场上限 4s。没有“又实时又 0.1Hz”这回事。[F]
6. **唯一可负担的“空间自由度”是顺序多点采样，不是阵列。** 同工况、同麦克风、3–5 个固定点，测相对传递差异；重复首点偏差 ≤1.5dB 才认扫描。它能排除房间/摆位，但不能定位到轴承。[I]
7. **听诊仪的核心设计取舍：把“诊断”定义为受控实验。** Agent 不决定“是什么故障”，只决定“下一次测什么、证据够不够、什么时候拒答”。这把不可辨识问题转成可执行的现场流程。[I]

## 1. 方法与证据分级

### 1.1 信息链模型

对一次现场采集，完整链路是：

```
激励（设备本体声源）
  → 传递（结构/空气/房间/距离/指向）
  → 采集（换能器/AGC/NS/采样率/摆位）
  → 特征（时域/频域/阶次/包络/调制）
  → 判据（阈值/基线/置信/滞回）
  → 结论（机制/故障归因）
  → 行动（复测/检修/验收/交接）
```

每一层都可能“说谎”。旧方案的问题是：**只在特征层和判据层做工程，把上游三层的不可观测性当成零**。

### 1.2 证据等级

| 标记 | 含义 | 例子 |
|-|-|-|
| `[F]` | 物理定律、代码常量、已跑过的测试、文档明确记录 | 48k/32768、5%/3σ、crestGateZ=3.5 |
| `[I]` | 由物理/信息论推导的工程取值 | 0.30m 默认距离、双 SNR 阈值、4s 上限 |
| `[U]` | 需要现场标定/标注才能确认 | 各泵型基线分布、轴承几何、真实故障名 |

> 本文不把 `[I]` 写成 `[F]`。凡是没有实测的方案，都保留 `[U]` 的验证动作。

### 1.3 判别方法的总原则

每个论断配一个**改前/改后成对实验**：只改一个变量，看输出是否按物理预测变化。不能做“加个模型试试”的不可证伪结论。

## 2. 七层逐层解构

### 2.1 激励层：设备本体到底在发声什么

**物理事实**

泵组的可听声由多机制叠加：转子不平衡（1×）、不对中（2×及谐波）、机械松动（分数阶/高次谐波）、滚动轴承冲击（BPFO/BPFI/BSF/FTF 及调制）、叶片通过（BPF=Z×rpm/60）、汽蚀/湍流（宽带高频）、电磁（2×电源频率，50Hz 系统为 100Hz）、结构共振（与转速无关的固定峰）。[F]

**旧方案的隐含假设**

> “声音是故障的指纹；一种故障对应一种谱形；谱形稳定即可命名。”

**物理上能否成立**

不成立，原因有三：

1. **叠加性**：\(p_{total}(t)=\sum_i p_i(t)\)，频域功率（非相干源）为 \(P(f)=\sum_k |S_k(f)|^2|H_k(f)|^2+N(f)\)。多个机制在同一频带叠加，观测是“和”，不是“标签”。[F]
2. **多对一**：1× 可来自不平衡、轴系共振、电磁、流致；2× 可来自不对中、两叶片 BPF、100Hz 电源。**同一谱线对应多个原因**。[F]
3. **工况调制**：同一故障在 50%/75%/100% 负载下谱形不同；汽蚀随流量/入口压力变化，可能只在某个工况出现。[F]

**失效时的现场表现**

- 同一台泵，早上“2×高”被判不对中，下午工况变了“2×低”，结论翻转。
- 两台同型号泵，一台轴承早期故障，另一台正常，谱形几乎一样（传递函数与摆位差 > 故障差）。
- 把 100Hz 电源线当成 2×（2800rpm 的 2×=93.3Hz，两者只差 6.7Hz）。[I]

**可验证的判别方法**

| 实验 | 操作 | 预测 | 判读 |
|-|-|-|-|
| 转速扫描 | 变频泵从 80%→100% 额定转速，稳定各 30s | 阶次线随转速移动；电源线固定 | 线随转速动→机械阶次；不动→电磁/ resonance |
| 负载扰动 | 阀门 50%→75%→100%，各 30s | 汽蚀/湍流随流量变；不平衡 1× 幅值随负载缓变 | 高频宽带随流量显著变→流致；1×稳定→机械 |
| 停机对照 | 停机后 30s 背景 | 背景谱不含阶次梳 | 停机仍有 100Hz→电磁/环境；有轴频→外部设备串扰 |
| 双点复测 | 同工况同点重复 3 次 | 阶次幅值差 ≤1.5dB | 差异大→传递/工况不稳，不是故障变化 |

**裁决**：保留“机制家族”的物理分类；**砍掉“单次稳态谱→故障名”**。见 §4 能力表。

### 2.2 传递层：从机器表面到麦克风，中间发生了什么

**物理事实**

- 声源到麦克风的传递函数 \(H(f)\) 包含直达、结构辐射、房间反射、距离、指向性、遮挡。单麦观测 \(X(f)=S(f)H(f)+N(f)\)，\(H(f)\) **未知且随摆位变化**。[F]
- 球面波远场声压 \(\propto 1/r\)，倍距离 −6.02dB；但近场不服从。
- **两个“近场”定义要分清**：
  - 反应近场（reactive）：\(r<\lambda/(2\pi)\)；1kHz 时约 0.055m。
  - 辐射远场边界（Fraunhofer）：\(r_f=2D^2/\lambda\)。泵壳等效尺寸 D≈0.3m 时：
    - 100Hz（λ=3.43m）：\(r_f=0.052\)m；
    - 1kHz（λ=0.343m）：\(r_f=0.525\)m；
    - 2kHz（λ=0.171m）：\(r_f=1.05\)m。
  - 所以 **0.5m 测点在 1kHz 以上已经处于近场/过渡区**，声压随位置快速变化，不能用 1/r 归一化。[I，基于 D=0.3m 假设]
- 房间轴向模态 \(f=c/(2L)\)：4m 房间 → 42.9Hz、85.8Hz，正好落在 46Hz 的 1× 与 2× 附近；驻波在节点/腹点可造成 **>10dB** 差异。[I]
- 1kHz 波长 0.343m；移动 0.17m 即半波长，相位反转，局部声压可变 >10dB。[F]

**旧方案的隐含假设**

> “固定 0.5m 就可复现；距离差可用 1/r² 归一化；换个人拿手机不影响。”

**物理上能否成立**

- “固定距离”只能保证**几何近似**，不能保证**传递函数一致**：手持角度、手机壳、人体遮挡、房间驻波、泵壳指向性都会改变 H(f)。
- 距离归一化只在**远场、自由场、同指向**成立；泵房不满足。0.5m 对 >1kHz 已在近场，归一化会产生系统性错误。[F/I]

**失效时的现场表现**

- 同一台泵，换一个测点，低频差 3dB、4–8kHz 差 10dB，被误判为“高频故障出现”。
- 基线在 A 点建，巡检到 B 点，异常分飙到 80，实际是房间腹点。
- 手机横竖屏/手持角度变化，高频指向性差异导致 4–8kHz 比值漂移。[I]

**可验证的判别方法**

| 实验 | 操作 | 预测 | 判读 |
|-|-|-|-|
| 距离扫描 | 0.3/0.5/1.0m，同工况，各 30s | 低频（<500Hz）近似 −6dB/倍距；高频偏离 | 高频偏离大→近场/指向/房间，不能归一化 |
| 横向移动 | 固定距离，横向 0.25m | 低频变化小、高频变化大 | 变化 >6dB→驻波/指向，需固定点 |
| 回访首点 | 多点扫描后回到首点 | 与首测差 ≤1.5dB/1/3oct | 超差→工况漂移，扫描作废 |
| 停机背景 | 停机测背景 | 背景平坦/无阶次 | 背景有峰→环境源，不是泵 |
| 互换手机 | 两台手机同点 | 绝对差大、相对谱形相近 | 绝对不可比，只能同机比较 |

**裁决**：保留“固定测点 + 几何记录”；**砍掉距离归一化/跨点比较**；新增“多点顺序扫描 + 回访一致性门”。见 §5。

### 2.3 采集层：手机不是声级计

**物理事实**

数字样本到声压的映射是：

\[
L_p = L_{dBFS} + 20\log_{10}\!\left(\frac{V_{FS}}{S\cdot G\cdot p_0}\right) + \Delta_{\text{mic}}(f)+\Delta_{\text{OS}}(f,t)
\]

其中 \(S\) 为麦克风灵敏度（手机 MEMS 典型 −42~−38 dBV/Pa，逐机 ±3dB），\(G\) 为增益（AGC 时变），\(V_{FS}\) 为 ADC 满量程，\(p_0=20\mu Pa\)，\(\Delta_{\text{mic}}\) 为频响（100Hz–10kHz ±3dB），\(\Delta_{\text{OS}}\) 为系统 NS/AEC/波束/重采样。[F]

- **EIN（等效输入噪声）** 25–35 dB SPL：低于此的弱特征被本底淹没。
- **AOP（声学过载点）** 115–130 dB SPL：超过即削顶，THD 上升，crest/kurtosis 失效。
- **AGC** 改变绝对幅度，且可能非线性压缩冲击；**NS** 可能删除 4–8kHz 目标特征；**AEC** 在泵房一般无参考，但系统可能仍启用。
- **采样率**：44.1k 会缺 22.05–24kHz（对泵诊断影响小），但重采样会改变相位/阶次窗；真值 48k 才可判读。[F]

**旧方案的隐含假设**

> “dBFS 加 `splAt0=120` 就是声压级；AGC 只是音量；48k 一定拿得到。”

**物理上能否成立**

不成立。`splAt0` 是一个**未标定的显示偏移**，不是麦克风灵敏度；AGC 是时变增益；浏览器/OS 可能在应用层之下做处理。绝对 SPL 的误差预算：

| 来源 | 典型误差 |
|-|-|
| 灵敏度逐机 | ±3dB |
| 频响 | ±3dB（100Hz–10kHz） |
| AGC 状态未知 | ±20dB 或更多 |
| OS NS/AEC/波束 | 不可量化，频带相关 |
| 合计（未校准） | **>±5dB，低频/高频更差** `[I]` |

**失效时的现场表现**

- 报告写“85dB(A)”，实际可能是 70 或 100dB；无法用于职业卫生/验收。
- AGC 把冲击压平，crest 从 5 降到 2.5，事件轨漏报。
- 削顶产生谐波，kurtosis 假性升高，误报轴承冲击。
- 44.1k 设备上 1× 跟踪窗偏差，轴频拟合偏 0.5Hz，被误判“转速异常”。

**可验证的判别方法**

| 实验 | 操作 | 预测 | 判读 |
|-|-|-|-|
| 校准器 | 94dB/1kHz 活塞发声器贴麦 | 读数偏移稳定；换机不同 | 偏移差 >3dB→不可跨机；只能单机相对 |
| 增益扫描 | 外部衰减 0/−10/−20dB | dBFS 应线性 −10/−20dB | 不线性→AGC/压缩，绝对幅度不可用 |
| 削顶注入 | 近距高音量，观察 ≥0.95 连续 3 点 | crest 下降、kurtosis 异常 | 事件轨必须 invalid |
| 采样率审计 | 读取 `AudioContext.sampleRate` 与真实文件头 | 44.1k 设备 | 必须标 invalid/禁用阶次 |
| OS 处理对照 | 录音机 App vs 本 App 同点 | 频谱差 >3dB 某带 | 系统处理介入，判据需绕开该带或拒答 |

**裁决**：**砍掉绝对 SPL**；保留 dBFS 相对声级；AGC/削顶/采样率作为硬门；外接校准麦列为 Phase 2 `[U]`。

### 2.4 特征层：你算的那些数，物理上代表什么

**物理事实**

- 频率分辨率 \(\Delta f = f_s/N = 1/T\)。48k/32768 → 1.4648Hz；Hann ENBW=1.5 bin → 2.20Hz。[F]
- 时间-频率不确定 \(\Delta t\cdot\Delta f\ge 1/(4\pi)\)：不能同时要 32ms 冲击和 0.1Hz 分辨率。[F]
- 轴频估计用 1×–5× 谐波梳加权回归：若单峰频率误差 σ≈0.5 bin=0.73Hz，5 个谐波 \(\sum(h-\bar h)^2=10\)，斜率 1σ≈0.73/√10=0.23Hz；6 窗合并 → 95% 约 ±0.19Hz。46Hz 下 0.3Hz=0.65%。[I]
- 包络分析：带通 1.5–6kHz，取 Hilbert 包络后 FFT；轴承阶次依赖几何（滚珠数 n、d/D、接触角）。通用 9 珠/d/D=0.20 与实际差 ±20% 很常见。[I]
- crest=peak/RMS；高斯噪声 N=4096 时理论 crest≈√(2lnN)=4.08；峰度（kurtosis）期望 3，标准差≈√(24/N)=0.077。冲击使峰度升高，正弦 crest=1.414、kurtosis=1.5。[F]
- 计权：A 在 46Hz 约 −32dB（50Hz −30.2dB）；用 A 计权看 1× 等于把它压掉 32dB，会系统性偏向高频故障。[F/I]

**旧方案的隐含假设**

> “0.68s 窗足够；特征与工况无关；通用轴承阶次能指认轴承；A 计权是‘标准声级’。”

**物理上能否成立**

- 0.68s 对 46Hz 的 1× 有 31.8 转，够；但对 1% 边带（0.46Hz）不够（需 2.2s）。[F]
- 1500rpm 的 0.68s 只有 17 转，**不满足 20 转**，阶次不可用。[F]
- 通用轴承阶次只能给“冲击重复率”，不能指认“内圈/外圈/滚珠”；几何未知时命名是猜。[I]
- A 计权适合职业噪声评价，不适合低频阶次诊断；判据必须用 Z（不计权）。[F]

**失效时的现场表现**

- 低转速泵“1× 跟踪”漂移，报“转速不稳”，实际是窗内转数不足。
- 包络谱在 165Hz 有峰，被报“外圈故障”，换一套轴承几何后峰在 142Hz，结论不成立。
- 2× 与 100Hz 电源线混在一起，A 计权后低频差异被压扁，无法分辨。
- 用 8192 点快窗做 1× 拟合，Δf=5.86Hz，46Hz 下 12.7%，拟合结果不可信。

**可验证的判别方法**

| 实验 | 操作 | 预测 | 判读 |
|-|-|-|-|
| 双窗长 | 0.17s vs 0.68s vs 2.7s，同段 | 峰宽按 1/T 变窄 | 0.17s 不用于轴频；2.7s 用于细边带 |
| 合成梳 | 注入已知 46Hz+谐波信号 | 跟踪误差 <0.3Hz | 超差→算法/窗长问题 |
| 几何输入 | 输入真实轴承 n/d/D/接触角 | 阶次移动 | 无几何→只报重复率，不报部件 |
| 计权对照 | 同段 Z vs A | 46Hz 差约 32dB | 判据看 Z；A 只显示 |
| 分辨率审计 | 打印 Δf/ENBW/窗内转数 | 与公式一致 | 不一致→实现错 |

**裁决**：保留时域/频域/阶次/包络；**升级**轴频跟踪与双窗；**降级**通用轴承命名为“重复率”；判据统一 Z。

### 2.5 判据层：阈值、基线、置信

**物理/统计事实**

- 机器间差异、工况差异、摆位差异的方差，往往大于早期故障的均值偏移；固定阈值跨机不可移植。[F/I]
- 基线马氏距离：20 维，对角协方差，\(d=\sqrt{\frac1{20}\sum z_i^2}\)，score=100(1−e^{−d/2.2})；score 60 对应 d≈2.02。**这是工程分，不是概率。** [F]
- 滚动 median/MAD 会把劣化吸收进“新正常”：设健康 crest 中位数 3.8，劣化后 5.5，门限=median+3.5×MAD 会跟着升到 7+，检测延迟趋于无穷。**冻结门**才能保持灵敏度。[F/I]
- 削顶/AGC 是乘性/限幅污染，任何基于幅值分布的判据在污染下都失效。[F]

**旧方案的隐含假设**

> “阈值可以跨机；基线可以自学习；置信度百分比就是故障概率；门限随数据自适应更稳。”

**物理上能否成立**

- 跨机不可移植：灵敏度 ±3dB + 频响 ±3dB + 摆位 H(f) 差异，足以让同一阈值在不同泵上误报/漏报。[F]
- 自学习基线在无监督下无法区分“正常老化”与“故障发展”；自动更新会把故障学成正常。[F/I]
- 启发式 confidence=0.45×top prob+0.3×separation+0.25×SNR 不是校准概率；不能当 P(fault)。[F，代码]
- 自适应门限在劣化时抬高，灵敏度下降；冻结门 + 显式重建才是正确策略。[F/I]

**失效时的现场表现**

- 新泵第一天误报，运维关通知；三周后真故障漏报。
- 基线包含了一次异常（比如那天有汽蚀），之后系统认为“这就是正常”。
- 报告写“置信度 87%”，用户理解为“87% 概率轴承坏了”，实际只是启发式分。
- 门限随劣化漂移，事件轨“越坏越安静”。

**可验证的判别方法**

| 实验 | 操作 | 预测 | 判读 |
|-|-|-|-|
| 冻结 vs 滚动 | 同一台已知劣化泵，30 天，A 组冻结门/B 组滚动门 | 冻结组检测更早、误报不增 | 滚动组延迟↑→禁止自适应 |
| 基线投毒 | 基线中混入 1 段异常 | 异常分下降/漏报 | 必须“基线仅健康验收数据” |
| 跨机移植 | 同阈值跑 3 台不同泵 | 误报率差异大 | 阈值必须按点/机标定 |
| 置信校准 | 有标注集上画 reliability diagram/ECE | 启发式分偏离对角线 | 不得称“概率”；改 ordinal |
| 削顶注入 | 削顶前后跑事件轨 | 事件率异常 | 削顶态必须 invalid |

**裁决**：保留基线异常检测；**降级**为“仅健康验收基线 + 冻结门 + 不自动更新”；**砍掉**“百分比=概率”的表达。

### 2.6 结论层：为什么“故障名”不可辨识

**物理/信息论事实**

从单次稳态观测 \(X(f)\) 到故障名 \(Y\)，需要条件概率 \(P(Y|X)\)。可辨识要求：不同 Y 在 X 上有可分支撑集，且有真值标签。实际：

- 支撑集重叠：1×/2×/BPF/电磁在同一频带重叠；传递函数 H(f) 进一步混合。[F]
- 标签缺失：没有拆检/维修记录，Y 是猜的；“疑似轴承”不是 ground truth。[F]
- 域漂移：泵型、工况、房间、手机都变；实验室分类器到现场精度下降不可控。[I]
- 代价不对称：误报导致停机/拆检；漏报导致事故。单一 accuracy 无意义。[F]

**旧方案的隐含假设**

> “方向打分 top-1 可以升级为故障名；置信度越高越可信；用户需要一个人格化的结论。”

**物理上能否成立**

不成立。没有逐类放行门槛，故障名是**不可辨识 + 不可校准**的组合。13 号样本方案已经给出放行条件（C31）：每类 ≥100 段真实样本、双人复核、recall/precision/F1/unknown/跨设备/相邻强度六道门。未过门，只能输出“机制家族 + 需复测”。[F]

**失效时的现场表现**

- 把“1×偏高”报成“不平衡”，实际是 46Hz 房间模态；用户去做动平衡，白花钱。
- 把“高频宽带升高”报成“轴承”，实际是阀门汽蚀；拆机后轴承完好。
- 把“2×偏高”报成“不对中”，实际是 100Hz 电源线；对中后无变化。

**可验证的判别方法**

| 实验 | 操作 | 预测 | 判读 |
|-|-|-|-|
| 盲测 | 隐藏标签，专家只看证据包 | top-1 机制一致率 | <70% 不配“诊断”，只能“筛查” |
| 拆检真值 | 维修前后拆检记录 | 标签可追溯 | 无真值→不进训练/不进结论 |
| 混淆矩阵 | 每类 vs 其他 | 相邻强度混淆 | >25% 不得放行该强度级 |
| 拒答测试 | 构造无基线/低 SNR/削顶 | 必须拒答 | 不拒答→红线 |
| 跨设备 | 换 3 台手机/3 个泵房 | 精度下降 | >10pp 不得放行 |

**裁决**：**砍掉字面故障名**（未过 C31 前）；保留“机制家族 + 验证实验 + 疑似/需复测”的措辞。见 03 §6。

### 2.7 行动层：从“建议检查”到“下一个最便宜的判别实验”

**物理/决策事实**

- 声学筛查只能提高/降低某机制的后验，不能替代振动、油液、温度、电流、拆检。[F]
- 现场行动有安全边界：带电开柜、带压拆阀、高温/有毒介质，不得由 App 指导越权操作。[F]
- 最有价值的行动不是“去修”，而是“用最小代价把不可辨识变成可辨识”：变工况、换点、复测、停机对照、加振动测点。[I]

**旧方案的隐含假设**

> “给一句通用建议（检查轴承/检查对中）就算闭环。”

**物理上能否成立**

不成立。通用建议不可执行、不可验证、不可交接；且可能诱导不必要的停机。

**失效时的现场表现**

- 报告写“建议检查轴承”，班组不知道怎么查、查完没有回填，案例断链。
- 每次结论都“建议停机检查”，用户不再相信。
- 交接班只看到“异常”，看不到“为什么、下一步、上次做到哪”。

**可验证的判别方法**

| 实验 | 操作 | 预测 | 判读 |
|-|-|-|-|
| 行动回填 | 每条建议后续 7 天回填“做了/没做/发现” | 可计算建议命中率 | 无法回填→建议设计失败 |
| 成本排序 | 复测/变工况/振动/拆检的成本 | 先做低成本高信息 | Agent 必须按信息增益/成本排序 |
| 安全审计 | 越权指令扫描 | 0 条越权 | 出现即阻断 |

**裁决**：保留“建议”；**升级**为“下一判别实验 + 安全前置 + 回填字段”；**砍掉**“远程指导拆机”。

## 3. 三个致命假设的量化反证

### 3.1 假设 A：绝对 SPL 可测

反证实验（改前/改后）：

1. 同一台泵、同一点，3 台手机录音，读 dBFS 并加 `splAt0`。
2. 同时用 94dB/1kHz 校准器贴麦，记录偏移。
3. 预测：三台手机偏移差 ≥3dB；频响在 4–8kHz 差 ≥3dB；AGC 开启时差异更大。
4. 结论：若差 >3dB，绝对 SPL 不可跨机；若 >5dB，连单机筛查都不可信。→ 只能相对。

### 3.2 假设 B：单麦可分离/定位

反证实验：

1. 两源同时发声（泵 + 扬声器播放 1kHz 纯音），单麦录 30s。
2. 尝试“分离”：任何单通道算法只能给出一路混合；改变扬声器相位/频率，混合随之变，但无法恢复泵的独立波形。
3. 预测：分离结果的泵成分仍随干扰变化；无法通过“独立成分”检验。
4. 结论：单麦无空间自由度；分离只能靠先验（阶次/调制/扰动），不是物理逆。→ 多点是唯一廉价空间信息。

### 3.3 假设 C：稳态谱可命名故障

反证实验：

1. 选 3 台已知故障（拆检真值）与 3 台健康，同型号同工况。
2. 只看单次 0.68s 谱，让 3 位工程师盲判故障名。
3. 预测：一致率低；1×/2× 机制混淆；传递差异被误读为故障。
4. 结论：若 top-1 一致率 <70%，故障名不可放行。→ 只给机制家族 + 验证实验。

## 5. 物理增量：顺序多点采样能做什么、不能做什么

### 5.1 数学

同工况、同麦克风、同增益，在点 \(i\) 观测功率：

\[
P_i(f)=|S(f)|^2|H_i(f)|^2+N(f)
\]

若源 \(S(f)\) 在一次扫描内稳定，则两点比：

\[
10\log_{10}\frac{P_i(f)}{P_0(f)}=20\log_{10}\frac{|H_i(f)|}{|H_0(f)|}
\]

这给的是**相对传递差异**，不是源位置。若近似自由场 \(H_i\propto 1/r_i\)，则理论上 \(-20\log_{10}(r_i/r_0)\)；偏离该斜率说明反射/指向/近场。[I]

### 5.2 能做的三件事

1. **选一个可复现的测点**：3–5 点中选背景最低、阶次最清、重复性最好的点。
2. **识别房间/摆位伪影**：距离扫描偏离 −6dB/倍距，或横向 0.25m 变化 >6dB，判为驻波/指向，不作为故障证据。
3. **找“表面最响区”**：固定距离 0.3m，沿泵壳 0.1m 网格扫描；相对高 6–10dB 的区域提示结构辐射强，但仍不能指认内部轴承。[I]

### 5.3 不能做的三件事

- 不能定位到轴承/叶片/阀门（单麦无方位）。
- 不能分离同时发声的多个源（扫描是顺序的，不是同时的）。
- 不能在工况漂移时扫描（必须回访首点 ≤1.5dB 才认）。

### 5.4 扫描协议（可执行）

| 步骤 | 操作 | 门 |
|-|-|-|
| 1 | 固定 rpm/流量，记录工况 | 稳态 ≥10s |
| 2 | 点 0：0.30m，正对泵壳，测 30s | 质量 ok |
| 3 | 点 1–4：同距离，横向/上下 0.1–0.2m | 每点 30s |
| 4 | 回点 0 复测 30s | 与首测 1/3oct 差 ≤1.5dB |
| 5 | 输出相对差表 + 结论 | 超差→扫描 invalid |
