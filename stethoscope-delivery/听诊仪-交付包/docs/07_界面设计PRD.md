# 07 · 界面设计 PRD

> 一句话：**界面只有一块仪表台和一个“开始听诊”；其余全部下沉，或者根本不出现。**

## 0. 结论先行

1. **主界面不做功能入口矩阵**：一块仪表台 + 一个主操作 + 一个设置入口（header 图标）。不做底部 Tab，不做九宫格，不做“更多功能”。
2. **仪表台默认 3 个模块**：波形、频谱、质量灯。其余三个（阶次 / 趋势 / 事件轨）按需切换，切换状态写入本地存储，冷启动保持。
3. **图标不是贴纸，是布局语法**：圆角只出现在“听”的位置（听点、主按钮的按下反馈、采集中的点），所有面板、卡片、分隔一律直边（r=0）或 2px 微圆角。
4. **三态永远双编码**：颜色 + 字形（实心 / 半环 / 断杠）+ 文字（有把握 / 证据不足 / 本次不作结论）。invalid 时机制区**整块移除**，不置灰。
5. **性能当设计约束**：单帧 ≤16.7ms、频谱 ≤30fps、三层 Canvas、采集期 DOM 零重建；界面里的“克制”必须由实现保证，否则一动就破功。

## 1. 调性继承：三条硬规则

| # | 规则 | 判据（违反即返工） |
|---|---|---|
| R1 | **圆只在“听”处** | 除听点/状态点/主按钮按压态外，任何容器 `border-radius` ≤ 2px |
| R2 | **只有墨与纸** | 除三态与黄铜状态点外，界面无第三种色相；无渐变、无发光、无投影（仅 1px 硬线） |
| R3 | **一屏一动作** | 任何页面同时可执行的“主要动作”≤1；次级动作以文字链形式出现，不与主按钮同权重 |

图标语法到界面的映射（写进组件规范，不是比喻）：

| 图标元素 | 界面落点 | 具体实现 |
|---|---|---|
| 圆 = 听点 | 采集中的状态点、结果页三态字形、波形上的“当前窗”标记 | 8–64px 实心圆，`border-radius:50%` |
| 直边 = 设备立面 | 面板、证据卡、设置分组 | `border-radius:0`，只用 1px 分隔线分区 |
| 相切 = 贴合 | 主按钮与屏幕底边的距离（贴住但不触边）、测点行与仪表台之间的零间隙 | 主按钮距底 24px；模块之间无外边距，仅内分隔线 |

## 2. 视觉调性系统

### 2.1 色板与深色反转规则

**浅色为默认**（泵房白天/强光下反光更低，米白比纯白少眩光）。

| Token | 浅色 | 深色（反转） | 用途 |
|---|---|---|---|
| `--ink` | `#1B211E` | `#E7E4DB` | 正文、标记、主按钮底 |
| `--paper` | `#EFECE3` | `#141816` | 页面底、图标底 |
| `--paper-2` | `#E6E2D6` | `#1B211E` | 仪表台底（比页面低一级） |
| `--line` | `#D5D0C1` | `#2C332F` | 1px 分隔线 |
| `--mist` | `#5C635C` | `#8C948C` | 次要文字、轴标签（纸底 5.24:1 / paper-2 4.78:1） |
| `--brass` | `#9C7B3F` | `#C39A54` | 仅“正在采集”状态点、超容差顶帽；**不用于文字**（纸底 3.34:1） |
| `--ok` | `#33584A` | `#82AE97` | 三态：有把握 |
| `--low` | `#7A5C24` | `#CBA46A` | 三态：证据不足 |
| `--bad` | `#8A3F32` | `#C98B7E` | 三态：本次不作结论 |

**反转规则**（不是“再设计一套深色”）：

1. 只交换 `ink` 与 `paper` 两组，形状、位置、字号、间距**完全不变**。
2. 三态色在深色下整体提亮（L 值 +18~24），保证在 `#141816` 上 ≥4.5:1；不改变色相，避免“同一状态两种含义”。
3. 深色底不用纯黑：`#141816` 带一点绿灰，与墨色同族，降低长时间注视的对比噪点。
4. 任何情况下不给文字加描边、加发光来救对比——那会在强光下变成脏边。

对比度实测（脚本计算，口径为 WCAG 2.1 相对亮度，见 §11 AC-11）：墨 / 纸 **13.86:1**；`--mist` 纸底 **5.24:1**、`--paper-2` **4.78:1**；三态色纸底 **6.75 / 5.25 / 6.26**；深色反转后墨 / 底 **14.09:1**、`--mist` **5.74:1**、三态 **7.21 / 7.73 / 6.38**。`--brass` 纸底仅 3.34:1，故只出现在非文字元素（7px 状态点、3px 顶帽），任何文字都不使用它。

### 2.2 字阶

单一中文无衬线 + 等宽数字。中文用系统字体栈，数字强制 `tabular-nums`（读数跳动时不抖位）。

| Token | 尺寸/行高 | 字重 | 用途 |
|---|---|---|---|
| `--fs-display` | 34 / 1.1 | 400 mono | 结果页主读数、计时 |
| `--fs-h1` | 22 / 1.3 | 600 | 页面标题、三态结论 |
| `--fs-h2` | 17 / 1.4 | 500 | 模块名、设置分组名 |
| `--fs-body` | 15 / 1.7 | 400 | 正文、Agent 提示 |
| `--fs-sm` | 13 / 1.6 | 400 | 说明、列表副行 |
| `--fs-xs` | 11.5 / 1.5 | 400 | 轴标签、单位、页脚 |
| `--fs-mono-lg` | 30 / 1.2 | 400 mono | 采集中计时、dBFS 读数 |

规则：**正文不小于 12px；数字不小于 16px**（03 §10.3）；同一屏内字阶不超过 4 级；不用字重做唯一层级（配合颜色与留白）。

### 2.3 间距与栅格

8 点栅格，页面左右边距固定 **20px**（390 宽下内容区 350px）。

| Token | 值 | 用途 |
|---|---|---|
| `--s1` | 4 | 图标与文字间隙 |
| `--s2` | 8 | 行内间距、chip 内边距 |
| `--s3` | 12 | 卡片内行距 |
| `--s4` | 16 | 模块内边距 |
| `--s5` | 20 | 页面左右边距 |
| `--s6` | 24 | 区块间距、主按钮距底 |
| `--s7` | 32 | 大区块分隔 |
| `--s8` | 40 | 引导页留白 |
| `--tap` | 56 | 最小热区（手套） |

### 2.4 圆角语义

| 元素 | 半径 | 理由 |
|---|---|---|
| 面板 / 证据卡 / 设置分组 | **0** | 设备立面是直的 |
| chip / 数据标记 | **2** | 仅去锐，不软化 |
| 主按钮 | **2** | 按下时内嵌一个 `50%` 的反馈点（唯一圆角动效） |
| 听点 / 状态点 / 采集点 | **50%** | 圆只属于“听” |
| 底部 sheet | **0**（顶部 1px 线） | 不用圆角抽屉的“消费感” |

禁止：`border-radius > 2px` 的卡片、胶囊按钮、浮动圆形 FAB（主操作是通栏直边按钮，不是 FAB）。

### 2.5 图标族

统一 24×24 网格，1.5px 线宽，只用直线与整圆/半圆，**不使用填充色块**（除三态字形）。

| 图标 | 语义 | 构造 |
|---|---|---|
| `mark` | 品牌标记 | 由 `icon_final.svg` 直接内联（圆 r200 + 立面 146×560 r28，同源几何） |
| `point` | 测点 | 十字准星 + 中心 2px 点 |
| `asset` | 设备 | 两条平行竖线 + 一条横线（机房立面抽象） |
| `offline` | 离线 | 断开的横线 + 一个点（不做云朵打叉） |
| `single-mic` | 单麦 | 一个实心点 + 一条短竖线（与图标同构） |
| `hold` | 长按 | 圆环缺口 + 中心点 |
| `check` | 有把握 | 实心圆 |
| `half` | 证据不足 | 半环（左半实、右半虚） |
| `slash` | 不作结论 | 一条斜断杠 |

### 2.6 动效原则

| 场景 | 时长 | 曲线 | 说明 |
|---|---|---|---|
| 模块切换（替换） | 160ms | `cubic-bezier(.2,.7,.2,1)` | 只做 4px 位移 + 透明度，不做缩放 |
| 结果页进入 | 200ms | 同上 | 内容区整体上移 8px，无弹跳 |
| 三态切换 | 120ms | linear | 只换字与色，不闪 |
| 采集点呼吸 | 2.4s 循环 | ease-in-out | 只改透明度 0.55→1，**不改尺寸**、不发光 |
| 长按进度 | 800ms | linear | 按钮内一条 2px 线从左到右 |
| 减少动态 | — | `prefers-reduced-motion` | 全部降为 60ms 淡入；呼吸点变静态 |

禁止：视差、粒子、数字滚动动画、成功撒花、震动以外的音效。

### 2.7 声音可视化语言（“证据，不是装饰”）

| 模块 | 画法 | 禁止 |
|---|---|---|
| 波形 | 单线 2px 墨色，按 min/max 抽稀；削顶段画一条 1px 断线标记，不填红 | 填充式波形、发光、镜像对称装饰 |
| 频谱（1/3oct） | 竖条宽 6 / 间隔 4；基线 1px 虚线；超容差带只在顶部加 3px 黄铜顶帽 | 彩虹色阶、面积渐变、3D 柱 |
| 阶次 | 5 条竖线 + `1×…5×` 标签；只标可靠阶次 | 梳状填充、转速表盘 |
| 趋势 | 两点连线 + ±1.5dB 容差带（两条虚线） | 面积图、移动平均美化 |
| 事件轨 | 1px 竖刻度为时间，事件为 3×8 短竖条 | 热力图、告警红块 |
| 质量灯 | 4 个指标行 + 一个 8px 三态点 | 仪表盘指针、百分比环形进度 |

## 3. 信息架构与导航

```
启动
 ├─(首次)→ 引导 4 步（可跳过，仅一次）
 └─ 主界面（唯一常驻页）
      ├─ 仪表台（模块切换，最多 3 个）
      ├─ 下一步动作（Agent 单行）
      ├─ 开始听诊 ──→ 采集中 ──→ 结果（三态）
      │                              ├─ 生成报告
      │                              ├─ 复测对比（可比时才出现）
      │                              └─ 交接包
      └─ header：设备/测点上下文 · 单麦 · 离线状态 · 设置
                                     └─ 设置（5 组二级页）
```

**为什么只有这些**（针对“不允许二级功能入口矩阵”）：

| 常见入口 | 本设计处置 | 理由 |
|---|---|---|
| 设备列表 / 任务列表 | 删除，降为 header 一行“3号泵 · P-03” | 现场是“到点即测”，不是“先选设备” |
| 历史 / 案例库 | 降为结果页“交接包”与设置内“报告”分组 | 巡检中不查历史，交接时才需要 |
| 报告中心 | 降为结果页主/次动作 | 报告是会话的产物，不是独立目的地 |
| 我的 / 账号 | 删除 | 单机离线优先，无账号概念 |
| 帮助 | 降为设置“关于” | 现场不会读帮助 |

导航规则：**单栈、无 Tab、无手势横滑**（戴手套易误触）。返回只有两个位置：左上 `←`（≥56dp 热区）与系统返回。

## 4. 页面清单与状态矩阵

| ID | 页面 | 主动作 | 次级动作 | 关键状态 |
|---|---|---|---|---|
| P0 | 引导（4 步） | 下一步 / 开始 | 跳过 | 仅首次；`tzp.guide.v1=1` 后不再出现 |
| P1 | 主界面 · idle | 开始听诊 | 设置、测点切换 | 模块组合、质量微灯、离线状态 |
| P2 | 采集中 | 长按结束 | 中止（草稿） | 计时、实时质量、削顶/AGC 提示 |
| P3 | 结果 · ok | 生成报告 | 复测对比、交接包 | 机制列表无序、3 条证据 |
| P4 | 结果 · low_confidence | 补测（回采集） | 生成草稿报告 | 机制无序、不排序、不显示百分比 |
| P5 | 结果 · invalid | 重采（回采集） | 结束并存草稿 | **机制区整块不存在**，只给修复清单 |
| P6 | 设置 | — | 返回 | 5 组折叠、深色反转、重看引导 |
| P7 | 模块切换 sheet | 应用 | 取消 | 最多 3 个；内存记忆 |
| P8 | 测点 sheet | 选定测点 | 新建测点 | 最近 3 点 + 摆位指纹 |

**状态矩阵（页面 × 三态）**

| 页面 | `ok` | `low_confidence` | `invalid` |
|---|---|---|---|
| P1 idle | 微灯=待采集；主按钮可点 | 同左（未采集无三态） | 同左 |
| P2 采集 | 绿点 + “质量 ok” | 黄点 + “SNR 偏低”，仍可结束 | 红点 + 削顶/AGC 条，结束进 P5 |
| P3/P4/P5 | 见上表 | 机制无序、无排名 | 机制区为 `display:none` |
| P6 设置 | 不受三态影响 | 同左 | 同左 |

**仪表台模块状态**（每个模块必须能表达“我没有数据”）

| 模块 | 有数据 | 缺前置 |
|---|---|---|
| 波形 | 实时线 + dBFS | “未采集”平线 + 提示 |
| 频谱 | 25 带竖条（31.5 Hz–8 kHz） | 轴 + “待采集” |
| 阶次 | 1×–5× | “转速不足 900 或 <20 转 → 不做阶次” |

| 质量灯 | 4 指标 + 三态点 | 全 `—` + “待采集” |

## 5. 仪表台规格与性能预算

### 5.1 模块表（默认展示 + 数据来源 + 刷新 + 降采样）

| 模块 | 默认 | 工具/数据来源 | 刷新率 | 降采样 / 抽帧 | 单帧成本预算 |
|---|---|---|---|---|---|
| 波形 | ✅ | `capture.acquire` 原始块 48k mono 16bit | 60fps 绘制 / 30Hz 数据 | 每像素列取 min/max（保留瞬态，不做单纯抽样），390 宽 ≈ 512 点 | ≤4ms |
| 频谱 | ✅ | `spectrum.compute`，FFT 32768（0.6827s，Δf 1.4648Hz）→ 1/3oct 25 带（31.5 Hz–8 kHz） | 计算 20Hz / **绘制 ≤30fps** | 带值取对数后 −85…−30 dBFS 映射到 112px 高；只重绘差异区域 | ≤6ms |
| 质量灯 | ✅ | `quality.evaluate` 指标（采样率真值/SNR/削顶/AGC/掉帧/静默） | 2Hz（状态变化才重绘文字） | 无（离散） | ≤1ms |
| 阶次 | — | `orders.track`（rpm、1×–5×、σ、转数） | 10Hz | 线条坐标缓存，只改 y | ≤2ms |
| 趋势 | — | `baseline.compare`（ready 才显示） | 1Hz（会话级） | 会话点最多 12 个，不抽帧 | ≤1ms |
| 事件轨 | — | `events.detect`（4096 点帧，crestGateZ 3.5） | 8Hz 聚合 | 120s 环形缓冲 → 每 2s 一格，最多 60 格 | ≤2ms |

**默认三个及理由**

- **波形**：唯一能“用眼睛确认贴对了没有”的模块；削顶与 AGC 在波形上直接可见，是采集期的自检工具。
- **频谱**：所有判据的来源（1/3oct 与阶次线），也是证据卡的最小单元；没有它，结论无处指回。
- **质量灯**：三态门的前置可视化。先看灯，再看图，避免“图好看就以为能判”。

默认不选阶次/趋势/事件轨：阶次依赖 rpm≥900 与 ≥20 转（现场常不满足），趋势依赖基线（首次必无），事件轨依赖门限冻结 ≥200 帧——三者默认出现会长期空置，属于“占位式复杂”。

### 5.2 Canvas 分层

| 层 | 内容 | 重绘触发 |
|---|---|---|
| L0（DOM） | 文字、数值、标签、三态 | 值变化（节流 10Hz），不重建节点 |
| L1 `canvas#wave` | 波形 | rAF，仅采集期 |
| L2 `canvas#spec` | 频谱条 + 基线 | 30fps，脏标记 |
| L3（同 L2 的静态缓存） | 坐标轴、网格、刻度 | 仅在 resize / 模块切换时重绘到 `OffscreenCanvas` |

**硬约束**

1. 单帧 ≤ **16.7ms**（p95，中端 Android，390×844，dpr≤2）。
2. 频谱绘制 **≤30fps**；质量灯 2Hz；阶次 10Hz。
3. **禁止每帧重建 DOM**：采集 30s 内 `.panel` 子节点数量变化 ≤5（只允许替换文本节点与 canvas 像素）。
4. 禁止每帧 `getBoundingClientRect` / `innerHTML` / 读取 `offsetWidth`（布局抖动）。
5. `devicePixelRatio` 上限 2；canvas 用 `{alpha:false}`，`willReadFrequently:false`。
6. 页面隐藏（`visibilitychange`）立即停 rAF；恢复时重建静态层。

### 5.3 采集期的界面节流表

| 元素 | 更新频率 | 原因 |
|---|---|---|
| 计时 `00:12` | 4Hz（250ms） | 1Hz 看起来卡，60Hz 触发重排 |
| dBFS 读数 | 10Hz | 人眼读数上限 |
| 波形 | rAF 60fps | 瞬态可见性 |
| 频谱 | 30fps | 与刷新上限对齐 |
| 质量灯文字 | 状态变化时 | 减少重排 |

## 6. 交互细节：单手、手套、强光、误触

### 6.1 单手可达

- 拇指区 = 屏幕底部 0–33%（y ≥ 565）。**所有完成闭环的动作都在这块区域内**：开始、结束、结果页主/次动作。
- 主按钮：高 **64**，宽 = 350（左右 20 边距），距底 **24**；文字左对齐 + 右侧一个 24px 听点，符合“贴住”语法。
- 顶部区域只放“可读不可点”的信息；唯一顶部可点项是设置（56×56），不参与关键路径。
- 任何需要两只手的操作（模块切换、测点编辑）都不是闭环必经步骤。

### 6.2 手套

- 关键动作（开始 / 长按结束 / 结果页主次动作）最小热区 **56×56**；次要入口（模块 tab、＋、设置）**≥44×44** 并向外扩 padding；相邻热区间距 ≥12。
- 不用 hover、不用双击、不用滑动条（滑块改步进按钮）。
- 文本/图标命中区用 `padding` 外扩，不依赖精确描边。

### 6.3 强光

- 正文与背景对比 ≥4.5:1；数字 ≥16px，主读数 30–34px。
- 不用 1px 浅灰文字；`--mist` 只用于非关键标签，且不低于 4.5:1。
- 不用纯白底（眩光），米白 `#EFECE3` 反光更低；深色模式只在手动切换时启用，不跟随系统强制反转（现场强光下深色反而难读）。

### 6.4 误触防护

| 风险动作 | 防护 |
|---|---|
| 结束采集 | **长按 ≥800ms**，按钮内一条线走完才生效；松手立即取消 |
| 中止 / 丢弃 | 二次确认（sheet 内两段式：继续采集 / 丢弃并存草稿） |
| 删除基线 / 删除案例 | 二次确认 + 需输入测点名后 3 字 |
| 生成报告 | 无确认（可重复生成，不销毁数据） |
| 导出 / 交接 | 一次性 sheet 确认（含接收人角色） |
| 误触模块切换 | sheet 需点“应用”，点空白取消 |

## 7. 无障碍与色盲

- **三态双编码**：颜色 + 字形 + 文字，三者同时存在。色盲模拟（Deuteranopia / Protanopia）下，绿/黄/褐会趋同，此时靠字形（实心圆 / 半环 / 断杠）与文字区分。
- 三态色不用于“装饰”：仅出现在结论区、质量微灯、结果页左规则线。
- 结果页结论区左侧 4px 竖线用状态色，同时上方有图标与文字，不依赖单一通道。
- 所有交互元素带 `aria-label`；三态区域 `role="status"` + `aria-live="polite"`（避免打断读屏）。
- 焦点顺序 = 视觉顺序（header → 仪表台 → 下一步 → 主按钮），不跳。
- `prefers-reduced-motion: reduce` 下取消所有位移动画与呼吸点。
- 字号跟随系统字体缩放（`-webkit-text-size-adjust:100%`），布局用 `rem`+`px` 混合，放大到 130% 不横向溢出。

## 8. 补足功能（以及为什么不破坏简洁）

| 补足项 | 落点 | 简洁性论证 |
|---|---|---|
| 测点命名 / 切换 | header 第二行（可点，打开 P8） | 复用上下文行，不新增入口；只在“换点”时展开 |
| 摆位指纹 `placement_fp` | 结果页证据卡第 3 张 + 设置“设备”组 | 作为“同点可比”的凭据出现，不常驻 |
| 复测对比 | 结果页次级动作（仅同点且可比时出现） | 情景化出现，不预置入口 |
| 交接包 | 结果页页脚文字链 | 一行动作，不占版面 |
| 离线模型状态 | header chip “离线 · 模板 v1.0” | 只读状态，点击给一段说明，不参与流程 |
| 单麦模式标识 | header chip “单麦 · 48k” | 常驻但仅占 1 行 11px，替代“多通道选择”入口 |
| 基线状态 | 质量灯模块内一行 + 趋势模块空态 | 由模块承载，不额外开页 |
| 会话草稿 | 中止时自动存，结果页顶部一行“草稿已存” | 无独立“草稿箱”页 |

**底线**：新增项只允许落在 **header / 结果页 / 设置** 三处；任何新页必须替换掉一个旧入口，否则不加。

## 10. 与既有深色工业 UI 的差异

| 维度 | 既有（旧监测台 08/09） | 本设计 | 变化理由 |
|---|---|---|---|
| 底色 | `#0E1116 / #141922 / #1A2030` 蓝调深 | `#EFECE3` 纸底为主，`#141816` 绿黑反转 | 泵房强光下深底反光且难读；蓝调偏“科技感” |
| 状态色 | 高饱和红/黄/绿 | 苔绿 / 暗黄铜 / 铁锈褐，饱和度 ≤35% | 低饱和降低疲劳与误读，配合字形双编码 |
| 首屏 | 设备列表 + 24h 漂移 + 告警中心 | 一块仪表台 + 一个按钮 | 巡检到点即测，不做导航 |
| 健康分 | 0–100 分环形 | 三态 + 关注级别（文字） | 分数制造伪精度 |
| 图表 | 密集指针、仪表盘、热力图 | 单线、竖条、刻度；无填充与色阶 | 证据优先，装饰归零 |
| 圆角 | 8–16px 卡片 + FAB | 面板 0、chip 2、只“听”处为圆 | 图标语法成为布局语法 |
| 动效 | 告警呼吸、数值滚动 | 只保留 160–200ms 位移/淡入 + 一个 2.4s 静默呼吸点 | 现场不需要“有生命感” |
