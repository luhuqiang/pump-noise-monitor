## 2. 已否决（不再展开，禁止回写成备选方案）

| 被否决项 | 原因 |
|---|---|
| 保留 PGlite（`idb://` + wasm） | 与 05 N09、06 §5 冲突；主 APK 无 wasm 且失败静默降内存；包体 4.5–6 MB |
| 按 R/N 一次性全量重写 | 无 git、无样本、可验收仅 15%，重写已工作的音频/签名链风险高 |
| v2.0 做授权门 | 核心功能未验收，授权只会拖慢闭环；旧授权包源码不可复现 |
| 实现双麦 | 无硬件、无样本，做出来也无法验收；只留接口 |
| 深色工业底为默认 | 07 是验收面，原型/图标/AC 全按浅色；改默认要重做 token 与资产 |
| 在线 LLM 可选 | 会引入网络权限、隐私材料与失败路径，违反离线验收口径 |
| 沿用 C01–C35 | 00 §5 表内确有 C42，删编号会让台账与表体不一致 |
| 复用 versionCode 5 | 已被 1.4 占用，覆盖升级会冲突 |
